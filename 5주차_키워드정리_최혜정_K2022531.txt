# 데이터 정제
1) 숫자 인코딩
=> 인코딩 : 정보의 형태나 형식을 변환하는 처리 또는 처리 방식, 문자 뿐 아니라 사진, 영상 등 다른 데이터 포맷에도 사용됨.
하나로 통일하지않고 여러 인코딩을 두는 이유는 데이터를 전송할 때 데이터의 크기를 줄여 최대한 빠르게 저장할 수 있게 하기 위함.

인코딩 종류 :  ASCII, CP949, 유니코드, ANSI, UTF-8, UTF-16, EUC-KR 등

파이썬에서는 기본 문자열이 유니코드고 유니코드를 제외한 나머지 인코딩된 문자는 바이트로 표현됨.
문자를 특정 코드로 인코딩 할 떄 encode() 함수 이용.
- 유니코드 값 - ord( ) 함수
- 유니코드 값을 문자로 - chr( ) 함수
현재 시스템의 인코딩을 알고 싶을때, sys라이브러리의 sys.stdin.encoding 이용.


2) 표준화, 정규화
- 변수들 간 척도가 다른 경우 데이터 표준화 (특성들의 값의 범위를 비슷하게 만듦.)
- 특성 스케일링(feature scaling) 또는 데이터 스케일링(data scaling)

*표준화
: 정규분포, 즉 종모양의 분포를 따른다고 가정하고 값들을 0의 평균, 1의 표준편차를 갖도록 변환

모수적방법, 중심극한정리 
: 무작위로 복원추출을 하면 연속형 자료의 평균에 대한 분포는 정규분포를 띔. (< 30개 이상의 표본의 경우 정규분포를 따른다는 가정하에.)

비모수적방법, 10개 미만의 표본의 경우(모수적 방법을 사용하지 못함)
: 자료를 크기로 나열하여 순위를 매긴 후 차이 비교.

=> [ 표준화 = (각데이터 - 평균)/(표준편자) ] 
평균까지의 거리로, 2개 이상의 대상이 단위가 다를 경우, 대상 데이터를 같은 기준으로 볼 수 있게 함. 모집단이 정규분포를 따르는 경우 N(0,1)인 표준정규분포로 표준화 하는 작업.

(예제)
1. numpy 이용.
std_data = (data - np.mean(data,axis = 0))/ np.std(data,axis = 0)
2. zscore 이용. import scipy.stats as ss 
std_data = ss.zscore(data)
3. sklearn 이용. from sklearn.preprocessing import StandardScaler
std_data =StandardScaler().fit_transform(data)


*정규화
: 정규화(normalization)는 특성 값의 범위를 [0, 1]로 옮김, 큰 값은 1로, 가장 작은 값은 0.
=> [ 정규화 = (각데이터 - 최소값)/(최대값 - 최소값) ] 

(예제)
1. 수식 이용.
data_ms = (data - data.min(axis = 0)) / (data.max(axis = 0) - data.min(axis = 0))
2. sklearn 이용.
data_ms = MinMaxScaler().fit_transform(data)

* minmax 스케일러는 하나로 학습하고 학습,테스트 데이터 같은 스케일러에 이용해야함
범위가 달라질 수 있기 때문.



# 평가
모델자체가 예측한값과 실제값 (테스트데이터의) 을 평가하는 척도, 모델의 성능 확인
맞은데이터/전체데이터 => 정확도

< 평가의 종류 > 재현율, 정밀도, f1score, roc, auc
- 일반적으로 회귀의 경우: 오차 평균값에 기반함. MAE, MSE 등
- 분류의 경우 : 정확도, 긍정 부정의 이진분류와 불균형한 레이블 값 분포 등 에서는 오차행렬, 정밀도, 재현율, F1score 이용

1) 정확도
: 정확도는 실제 데이터에서 예측 데이터가 얼마나 같은지
=> 정확도(Accuracy) = (예측 결과가 동일한 데이터 건수) / (전체 예측 데이터 건수)

2) 오차행렬(confusion matrix)
: 이진 분류에서 잘 활용되는 성능 지표. 예측 오류가 얼마인지와 더불어 어떤 유형의 예측오류가 발생하고 있는지 함께 나타내는 지표.

모델을 평가하는 요소는 결국 모델이 내놓은 답과 실제 정답의 관계로 정의를 내릴 수 있음.
정답이 True 와 False 로 분리되고, 분류 모델 또한 True 와 False 의 답을 내놓음.
그래서 2 X 2 matrix로 case 분리됨.
=> 각 case, 표는 실제값이 positive인지 negative인지와 예측값이 positive인지 negative인지를 나태냄. 
- True Positive(TP) : 실제 True인 정답을 True라고 예측 (정답)
- False Positive(FP) : 실제 False인 정답을 True라고 예측 (오답)
- False Negative(FN) : 실제 True인 정답을 False라고 예측 (오답)
- True Negative(TN) : 실제 False인 정답을 False라고 예측 (정답)


3) 정밀도(precision)와 재현율(recall)
- 정밀도 : Positive로 예측한 경우 중 실제로 Positive인 비율. 즉, *예측값이 얼마나 정확한가.
  TP/(TP+FP)
- 재현율 : 실제 Positive인 것 중 올바르게 Positive를 맞춘 것의 비율. 즉, *실제 정답을 얼마나 맞췄는가
  TP/TP+FN

> 암 검사를 위해 병원을 찾아온 사람에게 암여부를 예측할때에는 재현율이 중요
> 메일이 왔는데 스팸메일여부를 판단하는 것은 정밀도가 중요

(예시, 정밀도와 재현율 한 번에 확인.)
​from sklearn.metrics import classification_report
print(classification_report(y_val, y_pred))

​4) F1스코어
: Precision과 Recall의 조화평균으로 주로 분류 클래스 간의 데이터가 불균형이 심각할때 사용, 점수가 높을수록 좋은 모델.
=> 2 X ((precisionXrecall)/(precision+recall))
​
(예시)
from sklearn.metrics import f1_score
pred = pipe.predict(X_test)
f1 = f1_score(y_test, pred)


+) 정밀도/재현율 트레이드오프
둘은 상호 보완적인 평가 지표, 임계값을 조정해 정밀도 또는 재현율을 높일 수 있음. 
- 임계값 : 0과 1로 분류하는 기준.
> 적절한 임계값을 찾아서 정밀도와 재현율을 효율적으로 만들어야 함.
> 이때, ROC-curve 와 AUC 등장.
> ROC-curve와 AUC를 사용하면 분류문제에서 여러 임계값 설정에 대한 모델의 성능을 구할 수 있게 됨.

5) ROC-curve
: 여러 임계값에 대해 TPR(재현율)과 FPR(민감도)그래프를 보여줌.
- sklearn.metrics의 roc_curve 이용.
# roc_curve(타겟값, prob of 1)
fpr, tpr, thresholds = roc_curve(타겟값, y_pred_proba(prob of 1))

*최적의 threshold(임계값)을 찾기
> threshold 최대값의 인덱스, np.argmax()
optimal_idx = np.argmax(tpr - fpr)
optimal_threshold = thresholds[optimal_idx]

print('idx:', optimal_idx, ', threshold:', optimal_threshold)
idx: 256 , threshold: 0.4633333333333334
최적의 임계값 0.4633.. 

6) AUC
: ROC곡선 밑의 면적을 구한 것으로 일반적으로 1에 가까울수록 좋은 수치, 0.5에 가까울수록 학습이 제대로 이루어지지 않은 모델.
-  AUC가 커지려면 FPR이 작은상태에서 큰 TPR을 얻을수 있어야함.
- sklearn.matrics 의 roc_auc_score 이용.
pred_proba = lr_clf.predict_proba(X_test)[:,1]
roc_score = roc_auc_score(y_test, pred_proba)
 


# 화이트박스(설명가능, 중요번수도출) - decisiontree / 블랙박스 - 딥러닝
설명가능한 딥러닝

1) 의사결정나무, Decision Tree 
: 한번에 하나씩의 설명변수를 사용하여 예측 가능한 규칙들의 집합을 생성하는 알고리즘.
- 데이터를 분석하여 이들 사이에 존재하는 패턴을 예측 가능한 규칙들의 조합으로 나타내며, 그 모양이 ‘나무’와 같다고 해서 의사결정나무라 불림.
- 의사결정나무는 분류(classification)와 회귀(regression) 모두 가능
> 분류의 경우 새로운 데이터가 특정 terminal node에 속한다는 정보를 확인한 뒤 해당 terminal node에서 가장 빈도가 높은 범주에 새로운 데이터를 분류.
> 회귀의 경우 해당 terminal node의 종속변수(y)의 평균을 예측값으로 반환.

* 의사결정나무는 구분 뒤 각 영역의 순도(homogeneity)가 증가/불확실성(엔트로피)가 최대한 감소하도록 하는 방향으로 학습을 진행.
엔트로피 외에 불순도 지표로 많이 쓰이는 지니계수(Gini Index) 공식.


2) 머신러닝, 딥러닝에서 말하는 블랙박스(Black Box)
: 아웃풋은 인간과 유사하게 원하는대로 도출할 수 있지만 어떻게, 무엇을 근거로 그러한 결과가 나왔는지 알 수 없는 것.
- 일반적으로는 많은 데이터와 지도 학습(supervised learning)을 이용하여 학습시키는데, 어떤 데이터가 주어지느냐에 따라 그 기준도 상대적으로 달라질 것. 그리고 내부적으로 원하는 아웃풋을 도출해내기 위한 여러가지 기준을 정하게 되는데 그 내부를 볼 수 없음. 계산이 매우 복잡함.


3) 설명가능한 AI(eXplainable Artificial Intelligence, XAI)는 인공지능이 나아가고 있는 진화의 한 단계로 인간이 인공지능의 작용 과정을 훨씬 더 쉽게 이해할 수 있도록 인공지능에 설명 능력을 부여함으로써 AI 결정에 대한 신뢰성이 향상됨은 물론이고 편향을 줄일 수 있음.
