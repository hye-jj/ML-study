<분류 알고리즘>
- 카테고리 변수 예측
(Classification은 Supervised learning 지도학습의 일종으로 기존에 존재하는 데이터의 Category 관계를 파악하고, 새롭게 관측된 데이터의 Category를 스스로 판별하는 과정)
> 지도학습의 Classification은 이미 정해진 카테고리(레이블) 안에서 학습하여 새로운 데이터를 분류하지만, 비지도학습의 Clustering은 정해지지 않은 카테고리(레이블)를 원하는 만큼 생성하여, 분류하는것이 가장 큰 차이점


1. 분류 알고리즘의 종류
- 나이브 베이즈
- 로지스틱 회귀
- 의사결정 나무
- 서포트 벡터 머신
- 최소 근접 알고리즘
- 신경망
- 앙상블


2. 분류의 원리,  정보 균일도! 
 균일 : 같은 것들끼리 모여있는것.
첫번째 질문에서 데이터가 반으로 나눠지기 원할때, 균일하게 나눠진다고 생각할 수 있음.

**엔트로피란? 불균질함의 척도.
1) 정보이득
: 엔트로피를 기준으로 1에서 엔트로피(불균질)을 뺌. 

2) 지니계수
: 접근방법은 같음.
불평등 지수를 나타내는 계수 - 경재학 용어
0일때 가장 평등. 1로 갈수록 불평등
0일때 비슷한사람들이 모여있는 것.


3. decision tree classifier
데이터에 있는 규칙을 학습을 통해 자동으로 찾아내 트리 기반의 분류 규칙을 만드는 알고리즘( if else를 자동으로 찾아내 예측을 위한 규칙을 만드는 알고리즘)

*지니계수*를 이용하여 분할함.
(머신러닝에서는 데이터가 다양한 값을 가질수록 평등하며 특정 값으로 쏠릴 때 불평등한 값)

- 나무가 너무 커피면 오버피팅됨. 
Decision Tree에서 많은 규칙이 있다는 것은 분류 방식이 복잡해진다는 것
> 과적합(너무 세세하게 가지가 나눠져 있어 학습하는 데이터에만 정확도가 높은 Overfitting 현상) 으로 이어짐.
1>가지치기를 이용해서 과적합 방지. (더 이상 분기하지 않도록.)
2>'앙상블' 방법이용해서 과적합 방지.(Decision Tree 를 여러 개 두어 모델을 만들어주는 Random Forest 가 앙상블 기법을 활용한 모델)


- white box알고리즘 : 고객들에게 설명해야 할 때 많이 사용을 한다. (쉽고 직관적)


4. feature importance
트리 기반 모델은 트리를 분기하는 과정에서 어떤 변수가 모델에 영향을 많이 주는 '중요한' 변수인지 측정할 수 있음. (각 변수가 얼만큼 분류 모델에 기여했는지에 대한 정보)

- 의사결정나무 에서는 지니계수를 사용하는데 각 노드에서 분류작업이 거쳐진 결과들의 불순도(지니계수)를 확인하여 각 변수의 중요도를 측정.
> 더 균일한(평등한) 결과를 배출시키는 노드(변수)가 있다면 해당 Feature의 중요도 높아짐.
>input 되는 X값 중에서 가장 중요한게 어딘지 찾는것.(어떤 변수에 더 중요성이 있는가)


5. 그리드 서치 CV
머신러닝에서 모델의 성능향상을 위해 쓰이는 기법중 하나, 사용자가 직접 모델의 하이퍼 파라미터의 값을 리스트로 입력하면 값에 대한 경우의 수마다 예측 성능을 측정 평가하여 비교하면서 최적의 하이퍼 파라미터 값을 찾는 과정.
딕셔너리형태로 파라미터에 해당하는 값들을 리스트에 여러게 넣어서, 최적의 하이퍼 파라미터 찾음.
ex) param_grid = { 
    'n_estimators': [200, 500],
    'max_features': ['auto', 'sqrt', 'log2'],
    'max_depth' : [4,5,6,7,8],
    'criterion' :['gini', 'entropy'] }


6. 앙상블
여러개의 분류기 생성하고, 그 예측을 결합 -> 더정확한 예측을 도출하는 기법, 여러 분류기의 예측값들을 수렴하고 결정하는 방법과 유사
( 랜덤포레스트 : 디시즌트리의 앙상블 )

>> voting 보팅 : 서로다른알고리즘의 결합, 다수결로 선택 ---> 예측 *확률 기반.
보팅방식 : 서로다른알고리즘(linear regression, Knearest neighbor support vector machine 등) 이용, 동일한 데이터셋

>> bagging 배깅 _ Bootstrap AGGregating: 모두 같은 유형의 알고리즘. 데이터 샘플링 - 복원추출 을 서로 다르게 가져가면서 보팅을 수행! 랜덤포레스트
데이터샘플링 : 부트스트래핑 분할 방식을 사용
동일한 알고리즘에 동일한 데이터셋을 이용하면 예측이 동일하게 될 것 -> 데이터를 나눠서 학습을 시킴. 복원추출.

>> bosting 부스팅 : 여러개의 분류기를 순차적으로! 학습하되, 앞에서 학습한 분류기가 예측이 틀린 데이터에 대해서 올바르게 예측할 수 있도록 다음 분류기에 가중치를 부여하면서 학습과 예측을 진행. XGBoost, LightGBM
Iteration1 분류잘못예측된값의 데이터에 가중치넣고 -  Iteration2 틀린 예측값의 데이터에 가중치 - Iteration3 반복 ->  잘못분류된 값에 가중치 높임 

>> stacking 스태킹 : 여러 다른 모델의 예측 결과값을 다시 학습데이터로 만들어서 다른 모델(메타모델)로 재학습시켜 결과를 예측하는 방법.

1) 보팅방법
하드보팅 : 다수결
소프트보팅 : 예측의 확률 평균으로 결정
> 일반적으로 소프트보팅이 예측성능이 우수하여 더 많이 사용.

*부트스트래핑
데이터를 나누는 방식.
동일한 분류기 학습을 하니까 서브샘플링해서 데이터셋 나눠 학습.

* 서브샘플링
- 데이터의 중복 발생
- 없어진 데이터도 있음
=> 복원추출 (전체데이터에서 뽑고 다시넣고 뽑고의 반복)
=> 복원추출의 이득 : 데이터를 조금더 다르게 모델에 넣기 위해서 (데이터 분포가 다르게 모델에 넣음) -> 데이터 분포를 왜곡시켜주는 효과(분포를 다르게하는 효과)

- test val train split 는 비복원추출.

2) 배깅방법 Bootstrap Aggregating
배깅 - 예측값 모아서
부트스트랩샘플링으로 나눠서 -> 트리여러개 심어(동일한 여러 분류기 이용) -> 보팅(소프트보팅) 하여 예측결과를 합침(Aggregation)

*Decision tree 를 배깅방법이용하여 앙상블 = random forest
> random : 변수를 임의로 선택. ( feature 여러개의 조합으로 묶음 )
> 데이터의 모습이 계속 바뀜. 부스트샘플링하고 모델 트레이닝할 때, 변수를 여러개로 사용하여서.
> 앙상블- 평가어느정도나오고, 트리기반 - 피쳐임포턴스도나옴 => 그래서 많이 이용됨.
